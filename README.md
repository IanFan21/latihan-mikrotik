# Latihan MikroTik Winbox

Website latihan mandiri MikroTik (RouterOS / Winbox) untuk siswa TJKT.
Dipakai sebagai pengganti praktik perangkat selama guru bertugas mengurus
ujian TKA.

**Situs live:** https://ianfan21.github.io/latihan-mikrotik/

## Cara pakai

1. Buka situs di atas dari HP atau laptop.
2. Isi nama dan nomor absen — website akan menghitung parameter pribadi
   (IP, pool DHCP, SSID, limit) yang dipakai di semua contoh soal dan tugas.
3. Ikuti panduan penggunaan 5 langkah di halaman utama.
4. Kerjakan tiap pertemuan secara berurutan: simulator Winbox, kuis,
   lalu tugas.

## Pertemuan 1 (bisa dibuka sekarang)

Login Winbox (MAC/IP), reset konfigurasi, identity, IP Address,
DHCP Client/Server, DNS, NAT, plus diagram topologi, kuis kasus &
hitungan, dan tugas berskenario ("Detektif Konfigurasi Rusak").

## Pertemuan 2 (terkunci sampai Rabu, 28 Oktober 2026 pukul 00.00 WIB)

"Boss Level: Warnet Mini".
