    Pertemuan 1 — Konfigurasi Dasar Sampai Internet Jalan

    Target pertemuan ini sederhana tapi fundamental: router diberi nama, punya IP untuk sisi LAN, membagikan IP otomatis ke klien (DHCP Server), menerjemahkan alamat klien ke internet (NAT), dan klien bisa membuka internet.

    Tujuan Pembelajaran

    • Menjelaskan fungsi Winbox dan perbedaan login via IP Address vs MAC Address.
    • Melakukan reset konfigurasi dan memahami akibat mencentang No Default Configuration.
    • Mengatur Identity, IP Address LAN, DHCP Client (WAN), DHCP Server, DNS, dan NAT Masquerade.
    • Menguji koneksi dengan ping dari router dan dari klien secara berurutan.

    Konsep yang Wajib Paham

    • Login MAC Address bekerja di layer 2 — dipakai saat router belum punya IP atau IP-nya tidak kamu ketahui. Syaratnya: satu jaringan fisik yang sama.
    • Default IP RouterOS adalah 192.168.88.1/24, user admin, password kosong (router baru keluaran terbaru memakai password di stiker bodi).
    • DHCP Client = router meminta IP ke jaringan atas (ISP/modem). DHCP Server = router memberi IP ke klien di bawahnya. Arahnya berlawanan — jangan tertukar.
    • NAT Masquerade menyamarkan semua IP privat klien menjadi satu IP milik router, supaya klien bisa “nebeng” internet.

    Langkah Praktik — Ikuti di Simulator & Catat Jalur Menunya

    Nilai di langkah ini memakai konfigurasi contoh kelas. Di tugas nanti, kamu menggantinya dengan parameter pribadimu.

    1. Login ke Winbox

      Buka Winbox → tab Neighbors → klik alamat MAC router yang muncul → user admin, password dikosongkan → Connect. Login MAC dipakai karena paling anti-gagal: tetap bisa masuk walau IP router berubah atau kosong.

      Winbox→Neighbors→MAC Address→Connect

    2. Reset konfigurasi (awal yang bersih)

      Reset membuat router kembali nol. Centang No Default Configuration supaya kita membangun konfigurasi sendiri dari kosong — di sinilah letak belajarnya. Setelah reset, router tidak punya IP sama sekali, jadi satu-satunya jalan masuk adalah login MAC Address.

      System→Reset Configuration→No Default Configuration ✓→Reset Configuration

    3. Beri nama router (Identity)

      Identity adalah nama router yang tampil di title bar Winbox dan di daftar Neighbors. Di kelas yang routernya banyak, nama yang jelas menyelamatkanmu dari salah setting router orang lain.

      System→Identity→isi nama→Apply

    4. Pasang IP untuk sisi LAN

      Klik tombol +, isi Address 192.168.88.1/24, Interface ether2. Kolom Network akan terisi otomatis 192.168.88.0. IP inilah yang nanti menjadi gateway bagi semua klien.

      IP→Addresses→+→Address: 192.168.88.1/24→Interface: ether2

    5. Minta IP ke jaringan atas (DHCP Client)

      Klik +, Interface ether1. Status harus berubah menjadi bound — artinya router berhasil menyewa IP dari modem/ISP. Tanpa langkah ini router tidak punya “kaki” ke internet.

      IP→DHCP Client→+→Interface: ether1

    6. Bagikan IP ke klien (DHCP Server via Wizard)

      Klik DHCP Setup lalu ikuti wizard: Interface ether2 → Address Space 192.168.88.0/24 → Gateway 192.168.88.1 → Pool 192.168.88.10–192.168.88.254 → DNS 8.8.8.8 → Lease Time isi 72:00:00 (klien menyewa IP selama 3 hari, jadi alamat klien tidak sering berubah).

      IP→DHCP Server→DHCP Setup→Next… sampai selesai

    7. Aktifkan DNS untuk klien

      Isi Servers 8.8.8.8 dan 1.1.1.1, lalu centang Allow Remote Requests supaya router mau meneruskan pertanyaan DNS dari klien. Tanpa ini, ping ke IP bisa jalan tapi membuka nama situs gagal — gejala klasik “internet nyambung tapi nggak bisa browsing”.

      IP→DNS→Servers→Allow Remote Requests ✓

    8. NAT Masquerade — kunci terakhir

      Di tab NAT, klik +: Chain srcnat, Out. Interface ether1, lalu tab Action → masquerade. Ini langkah yang paling sering terlupa dan paling sering jadi penyebab “sudah setting semua tapi internet tidak jalan”.

      IP→Firewall→tab NAT→+→chain=srcnat, out=ether1, action=masquerade

    9. Uji berurutan, jangan asal tebak

      Buka terminal di router, lalu uji dari titik paling dekat ke paling jauh. Urutan ini adalah cara teknisi menemukan letak putusnya koneksi:

      [admin@MikroTik] > ping 192.168.88.1 count=3 → diri sendiri, harus reply
      [admin@MikroTik] > ping 8.8.8.8 count=3 → internet via IP
      [admin@MikroTik] > ping google.com count=3 → DNS ikut teruji

      Terakhir uji dari PC klien: klien harus mendapat IP di rentang pool, gateway 192.168.88.1, dan bisa ping ke nama domain.

    Tugas Pertemuan 1 — “Operasi Internet Pertama”

    TOTAL 100 POIN

    Kerjakan di buku laporan dengan bahasamu sendiri. Semua angka memakai parameter pribadimu — buat dulu kartunya di bagian Parameter Pribadi bila belum. Tombol salin di bawah menyalin teks tugas beserta parametermu.

    1. Peta Jaringan Versimu (25 poin). Gambar topologi jaringanmu (Internet → router → 2 klien) lalu lengkapi tabel: Identity routermu, IP LAN, alamat network, gateway klien, rentang DHCP pool, dan DNS. Semua nilai diambil dari kartu parametermu — bukan dari contoh kelas.
    2. Rute Menu dari Nol (25 poin). Tuliskan urutan langkah lengkap (jalur menu + nilai yang diisi) untuk membangun konfigurasi dari router hasil reset No Default Configuration sampai klien bisa internetan, memakai nilaimu sendiri. Urutan yang salah tempat (misalnya NAT dibuat sebelum IP LAN) akan mengurangi nilai — susun seperti teknisi yang benar-benar bekerja.
    3. Detektif Konfigurasi Rusak (30 poin). Seorang teman mengirim potongan konfigurasi ini dan mengeluh internet tidak jalan. Ada tepat 3 kesalahan. Temukan ketiganya, jelaskan akibatnya, dan tuliskan perbaikan yang benar:
      /ip address add address=192.168.50.1/24 interface=ether1
      /ip dhcp-client add interface=ether2
      /ip firewall nat add chain=srcnat out-interface=ether2 action=masquerade
      Petunjuk arah berpikir: perhatikan di interface mana setiap perintah dipasang, hubungkan dengan topologi ether1 = WAN dan ether2 = LAN.
    4. Kasus Ruang Sebelah (20 poin). PC klien mendapat IP 192.168.88.10 dari routermu dan berhasil ping ke gateway, tetapi gagal ping ke 8.8.8.8 — padahal dari terminal router, ping ke 8.8.8.8 berhasil. Tuliskan: (a) dua kemungkinan penyebab paling masuk akal, (b) menu yang kamu buka untuk memeriksa masing-masing, (c) urutan pemeriksaanmu dan alasannya. Jawaban “karena NAT” saja tanpa menu dan urutan tidak mendapat poin penuh.

    Glosarium Istilah

    Kamus mini untuk istilah yang muncul di kedua pertemuan. Kalau saat mengerjakan tugas kamu lupa arti sebuah istilah, cek di sini dulu sebelum bertanya.

    Winbox
    Aplikasi Windows untuk mengkonfigurasi RouterOS lewat tampilan grafis (GUI).
    RouterOS
    Sistem operasi MikroTik yang berjalan di router — otaknya perangkat.
    Neighbors
    Daftar router MikroTik yang terdeteksi di jaringan lokal yang sama, lengkap dengan MAC & IP-nya.
    MAC Address
    Alamat fisik perangkat jaringan di layer 2; dipakai login Winbox saat IP belum ada.
    Identity
    Nama router yang tampil di Winbox dan daftar Neighbors.
    DHCP Client
    Fitur router untuk meminta alamat IP dari jaringan di atasnya (modem/ISP).
    DHCP Server
    Fitur router untuk memberi alamat IP otomatis ke klien di bawahnya.
    Pool
    Rentang alamat IP yang boleh dibagikan DHCP Server ke klien.
    Lease Time
    Lama waktu klien “menyewa” satu alamat IP dari DHCP Server.
    Gateway
    Pintu keluar klien menuju jaringan lain; biasanya IP LAN milik router.
    NAT Masquerade
    Menyamarkan IP privat klien menjadi IP router agar bisa mengakses internet.
    DNS
    Penerjemah nama domain (mis. google.com) menjadi alamat IP.
